# Generated reports

Generated boot, gather, and release reports must not be committed to this public repository when they contain local paths, usernames, hostnames, infrastructure details, or unapproved records.

Keep working reports in an access-controlled working lane. Preserve an approved permanent record in 📚 DrMarchand’s ⚛︎ Library only after provenance, validation, checksum where applicable, custody receipt, and authorized-human approval.

The generated report files previously stored here remain in Git history unless a separately approved history rewrite or repository replacement is completed.
